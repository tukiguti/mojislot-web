# ドット絵キャラの作画仕様（mojislot）

クイズの出題者を **48×56 のドット絵**で描くための決めごと。マップ1枚＝キャラ1体。

## 使い方

```bash
# 描いたら必ず通す（桁ずれ・未定義色はここで落ちる）
python3 tools/pixel_kit.py tools/pixel/<名前>.txt --preview /tmp/<名前>.png

# 使える文字と色の一覧
python3 tools/pixel_kit.py --palette
```

プレビューは **左が6倍・右が実寸3倍**。6倍だけ見て整えると実寸で潰れる描き込みに
気づけないので、**必ず両方を見る**こと。画像は Read ツールで開いて自分の目で確認する。

## マップの書式

- **48桁 × 56行**ちょうど。1文字＝1色
- 先頭の `#` 行はコメント（何行でも可）
- 透過は `.`

```
#（コメント）
................................................
................KKKKKKKKKKKK....................
   …56行…
```

## 画面の中での位置づけ

- 液晶の地色は **#2A1830（暗い紫）**。この上に置かれる
- 実際の表示は**3倍（144×168）**。細かい描き込みは消える
- 顔の表情で「出題／正解／不正解」を伝えるので、**顔まわりを主役**にする

## パレット（抜粋）

| 文字 | 用途 |
|---|---|
| `K` `k` | 輪郭。K＝外周（地色より暗い）／k＝内側の線 |
| `2` `h` `H` `L` `l` | 髪（暗→明）。既定は黒髪 |
| `d` `s` `S` | 肌（暗→明） |
| `W` `e` `E` `D` `X` | 目（白／虹彩明／虹彩／瞳／最暗） |
| `M` `m` | 口／舌 |
| `n` `c` `C` | 服・白系（暗→明） |
| `1` `3` `4` | 服・藍系（作務衣・つなぎ・制服） |
| `5` `6` `7` | 服・生成り系（白衣・前掛け・手ぬぐい） |
| `r` `R` `p` | 赤系（鉢巻・法被・リボン） |
| `g` `G` `q` | 緑系（エプロン） |
| `B` `b` `Y` `y` `N` | ほお／寒色／金／金の明／金属（眼鏡） |

## 守ること

1. **光源は左上ひとつ。** 右下ほど暗くする。外周を一律に暗くする「ピロー塗り」はしない
2. **輪郭は外周を暗く、内側の線は明るく**（色トレス）。全部同じ濃さだと平らなシールになる
3. **地色より暗い輪郭を外周に置く。** これがないと暗い液晶の上で形が消える
4. **色数は 25 色以内**を目安に。多いほど散らかる
5. **明度だけ動かさない。** 暗い側は青〜赤へ、明るい側は黄へ色相をずらす。肌の影は赤味を足す

## この解像度で分かっていること（踏んだ失敗）

- **表情はサイズではなく形で変える。** 目を1〜2ドット大小しても読めない
- **前髪の房を輪郭で深く切ると「牙」に見える。** 谷は浅くし、房は内側の線で表す
- **もみあげを太い雫形にすると「動物の耳」に見える**
- **バストアップでは髪の長さが読めない。** 肩から下はシャツに隠れる。効くのは前髪と、
  頭の高さで横へ張り出す形
- **頭頂は1行目。上へ伸ばす余白がない。** 逆立てた毛は画面外へ切れる
### 性別と年齢（`FINDINGS_boy.md` の実測。1要素ずつ振って比較した結果）

- **目の背の高さが単独で性別を反転させる。** 3行（まつ毛1段＋虹彩2行）＝男性、
  5行（虹彩4行＋下瞼）＝女性。他をすべて男性側に振っても**取り返せない**。
  縦に伸びると白目と虹彩が増えて光が入り、「潤んだ目」になるため
- **眉の可動域は2〜3行しかない。** 太さは2行が必須（1行にすると顔から意志が抜けて
  中性化する）。目に近すぎると帯になり、離しすぎると前髪に埋もれて消える
- **まつ毛は男女の一次元軸ではない。** 2段＝女性化・年齢が上がる、1段＝最適、
  0段＝女性化はしないが「眠そう・弱い」顔になる。**負ける方向が別**
- **あごは年齢を動かすが性別は反転しない。** 目と眉が男性側に決まっていれば、
  丸あごでも男のまま
- **頭身は性別にまったく効かない。年齢だけが動く。** 頭を大きくすると小学生、
  肩を広げると高校生以上。顔が同じでも肩幅だけで年齢が変わる
- **髪はシルエット最大幅が「どの高さにあるか」で読まれる。**
  上1/3にあれば短髪の男性、下にあるとマッシュルーム／おかっぱになって中性化する。
  横へ大きく張り出させると帽子かツインテールに見える

### 表情差（出題／正解／不正解）

出題の顔から**差分で**作る（`tools/gen_faces.py`）。素体を複製して手で直すと顔の作りが
ずれて別人になる。効く順は次のとおりで、**目そのものは触らない**（潰れて眉と一体化する）。

1. **顔の外の記号** — 実寸ではこれが差の主役。正解＝きらめき（十字）、不正解＝汗
2. **口** — 面積があり形が読める。開ける／閉じる＋口角の上下
3. **眉の傾き 1〜2ドット** — 効くが動かせる幅が狭い。眼鏡で隠れている人には使えない

- **きらめきは十字でよい**（中心を明るく四方に金）。輝きの記号なので十字が正解
- **汗を線で描くと「＋」に見える。** 塗り詰まった塊（上1ドット・下2×2）にする
- **口の線の下に影が残ると塊になる。** 口角を下げるときは間の影も消す。
  残すと口から垂れているように見える
- **鼻の直下に口の線を置くと髭になる。** 1行下げて離す
- **素体がすでに笑っている人は、正解が素体とほぼ同じになる。** きらめきで差を付け、
  代わりに不正解側を大きく変える

### 塗りの落とし穴

- **同じ文字が別の部位で使われる。** 「肌の影」を条件なしで置いたら暗い髪の上に
  サーモン色の斑点が出た。「服の影」が口の中の歯まで塗り替えた。塗り分けは必ず
  **「今そこが何色か」**で条件を切る
- **顔の陰影を左右で割ると「お面」になる。** 縦の継ぎ目が走る。斜めの境界にする。
  ピロー塗り禁止と同じ話が左右分割にも当てはまる
- **6倍で良くなる処理が3倍で潰れることがある。** 虹彩を暗くすると6倍では男性度が
  上がるのに、3倍では目が黒い塊になって眉と一体化し、かえって読めなくなった
